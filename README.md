# ☕ Velvet Café

Velvet Café is a modern and responsive café website designed using HTML, CSS, JavaScript, and Bootstrap 5.

The project demonstrates several important Bootstrap components and features, including Navbar, Carousel, Navs, Collapse, Modal, and Scrollspy.

## 🌐 Project Overview

Velvet Café is a one-page café website where visitors can explore the café menu, learn about the café, view upcoming events, read frequently asked questions, and make a table reservation.

The website is designed to provide a clean, warm, and modern café experience across different screen sizes.

## ✨ Features

- Responsive Navbar
- Bootstrap Carousel
- Bootstrap Navs for menu categories
- Bootstrap Collapse for FAQ section
- Bootstrap Modal for table reservation
- Bootstrap Scrollspy
- Responsive design for mobile, tablet, and desktop
- Interactive reservation form
- Hover effects and smooth visual transitions
- Café menu sections
- Events section
- About section
- Contact section
- Footer with social media icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
